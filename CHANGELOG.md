# Changelog

All notable changes to this crate are recorded here. The crate follows [semantic versioning](https://semver.org), independent of the OATS schema versions; see "Versioning policy" in the README.

## 0.0.1 (unreleased)

First release.

- Bundles OATS 0.8.0 (12 schemas, including `ranking`), copied unchanged from the `oatschema/oats` release tag.
- `SCHEMA_VERSION`, `SchemaName`, `available_versions`, `schema_json` and `Error`.
- `schema`, with the `serde_json` feature.
- Minimum supported Rust version: 1.85.
